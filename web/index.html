  1. 搜索与发现

    搜索栏可选择标签、作品 ID 或画师；多个标签用 ; 分开。作者同名时可根据头像、UID 和简介选择。发现页提供推荐、榜单和关注新作，每页最多 36 件。

  2. 查看图片

    单击等待 0.65 秒后查看，双击进入作品详情。我的账号 → 设置 → 预览与查看，可分别选择原比例自适应／规整网格，以及画面内放大／图片弹窗。

    弹窗用左右箭头或键盘方向键翻图，× 或 Esc 关闭。默认显示预览清晰度；点击下方「查看原图」才加载原图，缓存 5 分钟。底部 −／＋切换小／中／大，以整个窗口面积的 1/4、1/3、2/3 为目标，保留比例并限制在屏内。

  3. 作者、标签与返回

    点击作者名进入主页，名字仍可选中复制；点击标签继续搜索。侧栏上方的前进／后退恢复浏览记录。返回优先保留原页面、已加载图片与滚动位置。

  4. 挑选与刷新

    左上角勾选框负责下载选择，查看图片不会改变勾选。多图作品右上角显示张数。空白处右键「刷新」只更新当前页面，后台更新不会直接替换正在阅读的作品。

  1. 我的账号

    资料、关注、粉丝、收藏、设置集中在同一页面。App 授权为默认方式，也可选网页登录；两种方式任选其一，各用对应登录状态。

  2. 云收藏与关注

    ❤ 收藏作品，作者旁的＋用于关注；已操作后显示对应状态。可选择公开／私密及收藏标签，设置中可固定默认方式。首次默认私密，收藏和关注都不会自动下载。

  3. 缓存与同步

    账号列表与已读取页面保存在本机。设置可立即同步，也可开关自动同步并自定义间隔，最低 3 分钟。其他设备的改动在同步后更新；需要时可手动清除账号缓存。

  4. 采集篮与下载

    勾选的作品进入采集篮，多图可逐张选择。点击作品进入独立详情，返回恢复列表。下载详情中选择目录、是否新建文件夹、清晰度和格式；默认目录也可在设置中保存。

    下载进度按完成张数推进，完成或失败显示标记。暂停的任务可继续，历史记录可打开保存目录。GIF 便于播放，MP4 需要本机 FFmpeg，ZIP 保留动图帧与延迟数据。

安全首次默认，单路下载，请求间隔较宽松。

普通最多两路下载，自动准备后续搜索页。

激进最多四路下载，提前准备后两件动图帧包。

请求模式即时生效并自动保存。账号设置中的其他改动需点击「保存设置」；底部「保存当前改动」可跳至保存处。遇到限频会等待冷却，期间可切换页面或暂停下载。

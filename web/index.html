下载任务

任务已暂停，点击继续后下载。

  1. 搜索

    选择标签、作品 ID 或画师，多个标签用 ; 分隔。同名作者先选候选。选好排序，再点「开始寻找」。最近搜索旁的垃圾桶清空记录，单条记录可用 × 删除。

  2. 排序与加载

    滑块下方显示当前排序。作者／标签跳转、推荐与榜单默认等待「开始加载」；加载中点击可中断，完成后可重新加载；榜单按钮会重新检查最新可取得榜次。关注新作自动加载，其他入口可在「设置 → 常规」开启自动加载，并选择是否显示加载按钮。

    按收藏数排序的范围：搜索最多 500 件候选；作者全部可见作品；榜单完整可取得榜次；推荐本次作品池。

  3. 预览

    单击 0.65 秒后查看，双击进入详情。设置可选画面内放大或图片弹窗。弹窗左右箭头翻图，× 或 Esc 关闭；底部 −／＋切换小、中、大，「查看原图」按需加载并缓存 5 分钟。

    敏感图片点击划线眼睛显示，离开且无交互 10 秒后重新模糊。

  4. 返回与刷新

    作者名可点击跳转，也可选中复制。侧栏箭头或鼠标侧键前进／返回；输入框内侧键用于撤销／重做。空白处右键「刷新」，失败图片单击重试。

  5. 以图找图

    从首页选择、拖入或粘贴图片，确认后上传 SauceNAO。官网可登录并手动验证，API Key 在设置中填写。结果使用网站缩略图。来源链接打开原站；Pixiv 标识进入站内检索。

  1. 登录与账号

    「我的账号」包含资料、关注、粉丝、收藏和设置。App 授权与网页登录任选一种。

  2. 收藏与关注

    ❤ 收藏作品，＋关注作者。可选公开／私密并编辑收藏标签，设置可固定默认方式。与下载勾选独立。

  3. 同步

    账号数据持续缓存。资料页可点击「同步账号状态」，设置中也可立即同步或清除缓存。手动同步无需等待；自动同步间隔至少 3 分钟。其他设备的改动同步后显示。新作红点提示上次查看后的更新，查看作者或新作流后清除；检测与红点可分别关闭。

  4. 采集篮与下载

    左上角勾选框负责选图，多图作品可进入详情逐张选择。采集篮保留选择，点击下载后确认目录、文件夹、清晰度与格式。

    进度按图片张数推进，✅ 成功、❌ 失败。暂停任务可继续，历史记录可打开目录。动图支持 GIF、MP4（需 FFmpeg）和 ZIP 帧包。

安全默认模式，单路下载，请求间隔较长。

普通最多两路下载，预加载后续搜索页。

激进最多四路下载，提前准备后两件动图帧包。

请求模式即时保存，其他账号设置点击「保存设置」。限频时自动冷却，验证提示按页面指引处理。

MOKU OFFLINE GUIDE

使用说明

这份说明随 MOKU 离线保存。打开和阅读不会连接 Pixiv；只有点击“检测网络”才会发起匿名连通测试。

快速开始

普通搜索中多个标签用 ; 或 ； 分开，例如“猫；夜景”；每件结果都必须同时具有全部输入标签。启用模糊搜索后，也会查找内置的二次元同义标签。输入 pid:作品ID 可直达一件作品；只看某位画师时输入 uid:画师ID，也可输入精确画师名 author:画师名。英文冒号与中文冒号“：”等价。

网络连接

开启 Windows 系统代理时，MOKU 使用该电脑当前启用的本机 HTTP 代理；开启 TUN 全局模式时，MOKU 的直连请求由系统路由接管。两者都关闭且无法直连 Pixiv 时，搜索会失败。

检测只匿名访问 Pixiv 主站和图片线路，不发送 Cookie；不会修改 Windows 系统代理，不会自动启动 VPN，也不会扫描本机端口。

尚未检测当前路线：待检测

遇到连接问题时，可在这里检查当前系统代理或 TUN 路径是否能访问 Pixiv。

Pixiv 主站：待检测图片线路：待检测

登录与隐私

密码、验证码和 2FA 只在 Pixiv 官方页面输入。选择保持登录时，登录状态加密保存在 Windows 凭据管理器，不保存在网页里。不支持 R-18G。

搜索与分页

每页显示 36 件作品，结果不足时可继续加载本页；旧页仍可回退重新加载。图片在打开对应页面时加载。

日间与夜间

右上角可切换全局主题，搜索、详情、采集篮、下载与弹窗同步换色。首次跟随系统主题，当前窗口刷新会保留选择。

下载与文件

默认以原图清晰度保存到 MOKU 的 downloads 文件夹，也可选择其他文件夹。标准清晰度是 Pixiv 缩小预览，动图为 600px 帧包。多页作品可逐页勾选；请尊重作者版权、作品用途和 Pixiv 平台规则。

SHA-256

SHA-256 是 MOKU.exe 的单向文件指纹，不包含账号、Cookie、路径或身份信息。可用 Get-FileHash .\MOKU.exe -Algorithm SHA256 与 SHA256.txt 核对。

常见问题

主站可用但图片失败：代理可能没有覆盖 i.pximg.net。
复制到其他电脑：请复制完整 MOKU 文件夹，并在目标电脑安装 WebView2 Runtime。
系统代理关闭：若未开启 TUN 且不能直连 Pixiv，MOKU 也无法连接。

LOCAL ACCOUNT CONNECTION

连接 Pixiv

为了账户安全，本应用不会要求你在此输入 Pixiv 密码，也不会把 Cookie 或 Token 保存到网页存储。

当前：未授权将在 MOKU 桌面登录窗口打开 Pixiv 官方页面；完成登录后会自动连接。
取消勾选时，会话仅保留到本次 MOKU 退出。密码、验证码和2FA只在Pixiv官方页面输入；不支持R-18G。

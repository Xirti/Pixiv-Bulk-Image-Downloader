## 功能

- **搜索与作者页**：多标签搜索、作品类型／AI／日期／内容范围筛选；作者同名候选、资料与作品列表。
- **发现**：推荐、榜单、关注新作；综合日榜、周榜、月榜、新人榜、原创榜。
- **两种列表布局**：原比例自适应或规整网格。查看、下载勾选、收藏和关注相互独立。
- **两种预览方式**：单击画面内放大或图片弹窗，双击进入作品详情；多图逐页查看，动图悬停预览。
- **我的账号**：资料、关注、粉丝、云收藏、设置。App 授权为默认方式，网页登录为兼容选项，无需两种都登录。
- **云端操作**：公开／私密收藏与关注、收藏标签编辑；本地状态缓存、自动同步与手动同步。
- **批量下载**：采集篮逐张选图，原图／标准清晰度、目录及分组设置，下载去重、暂停恢复与历史记录。
- **动图导出**：原始帧 ZIP + JSON、GIF，或使用本机 FFmpeg 导出 MP4。
- **桌面界面**：中性色磨砂风格、日夜主题、紧凑侧栏、前进／后退、窗口拖动与缩放。

## 开始使用

**运行环境：** Windows 10/11 x64、Microsoft Edge WebView2 Runtime，以及可访问 Pixiv 和图片 CDN 的网络。

1. 在 [v2.0.0 发布页](https://github.com/Xirti/Pixiv-Bulk-Image-Downloader/releases/tag/v2.0.0) 下载 `MOKU-v2.0.0-Lite-windows-x64.zip`。
2. 完整解压，运行 `MOKU/MOKU.exe`。便携包已包含 Python 运行依赖，保留整个程序文件夹。
3. 在侧栏「我的账号 → 资料」选择 App 授权或网页登录，按官方页面提示完成登录。
4. 搜索或进入「发现」，查看作品并勾选需要下载的图片。
5. 在作品详情或采集篮选择保存位置、清晰度和格式，再开始下载。

首次启动展示使用说明；右上角「？ 使用说明」随时可打开。说明分为浏览与预览、账号与下载、模式与网络三栏，窗口尺寸固定，内容区可滚动。

## 浏览与预览

搜索栏可切换标签、画师和作品 ID，也支持以下输入：

| 输入示例 | 用途 |
| --- | --- |
| `猫耳` | 按标签搜索 |
| `猫耳;初音ミク` | 多标签组合，结果同时包含全部标签 |
| `pid:123456` | 按作品 ID 查找 |
| `uid:123456` | 按作者 UID 查找 |
| `author:画师名` | 按名字搜索作者，出现同名时选择候选 |

多标签用 `;` 或 `；` 分隔，最多6个不同标签，每个最多60个字符。日期按日本时间计算，包含起止当天；可选全年龄、R-18 或全部内容，受当前账号权限限制。

每页最多36件。发现中的推荐与榜单保留来源顺序，关注新作按时间合并。App 榜单显示来源序位，不伪造官方名次或日期；Web 有明确榜次信息时按实际数据展示。

「我的账号 → 设置 → 预览与查看」可分别选择列表布局和单击查看方式。全局布局适用于搜索、作者、发现和账号作品列表；采集篮固定使用规整视图。

- **画面内放大**：单击等待650毫秒后展开，再单击恢复；双击取消待执行单击并进入详情。保持图片比例和屏内边界，极端长图可使用0.4–2.5比例窗口。
- **图片弹窗**：单击打开，左右箭头或方向键翻页，× 或 Esc 关闭。底部「− / 小中大 / ＋」直接调整大小，「查看原图」位于左侧。三档以整个应用窗口面积1/4、1/3、2/3为目标，受原比例和屏内空间限制；关闭后记住档位。
- **多图加载**：新页解码后才显示，等待时标注目标页；失败可重试。已加载预览可复用，只准备相邻下一张预览；连续翻页保留最终目标。
- **原图按需查看**：弹窗默认使用预览清晰度，明确点击后才加载原图。原图内存缓存5分钟，容量最多96MiB／6张；显示中的过期图关闭后释放。下载清晰度独立，不因查看而改变。

作者名和 UID 可选中复制；点击作者进入主页，点击标签继续搜索。返回优先恢复原批次、页码、滚动位置和已加载预览。空白处右键「刷新」只更新当前页面，后台准备不直接替换正在阅读的列表。

## 账号、云收藏与同步

App 和 Web 各自使用对应授权；选择一种即可，数据请求不静默混用另一种凭据。网页方式的能力以当前可读取接口为准，不会为缺失能力自动借用 App 登录。

❤ 用于收藏作品，作者旁的＋／√用于关注状态；详情页可编辑公开／私密和收藏标签。首次预选私密，设置可固定默认方式。收藏、关注不会自动下载，图片查看也不会修改下载勾选。

账号资料、关注、粉丝、收藏、标签与已读列表页按账号及登录方式缓存在本机。打开操作菜单使用本地已知状态，提交时处理冲突；其他设备的改动通过同步更新。

自动同步默认开启，间隔可自定义，最低3分钟、无设定上限。设置「立即同步」可主动同步，关闭自动同步时仍可使用；右键刷新只更新当前页面。清除账号缓存保留登录、设置、采集篮、下载任务和已下载文件。关注卡片的 `NEW` 为本地观察标记，不代表 Pixiv 官方全量未读状态。

修改账号设置后点击「保存设置」；底部「保存当前改动」可直接跳到保存处。请求模式即时生效并自动保存。

## 下载与恢复

勾选作品加入采集篮，多图可逐张选择，最多选择1,000张。作品详情右上为图片舞台，右下负责下载选图；采集篮详情使用同一套查看组件，进入和返回保留来源位置。

下载可选择原图或标准清晰度、目录、是否新建文件夹及保存格式。静态图保留源格式；动图可保存 ZIP + JSON、GIF 或 MP4。导出 MP4 需要支持 `libx264` 的本机 FFmpeg，加入 `PATH` 后重启程序。

圆角进度条按图片保存结果推进，运行中显示条纹，完成显示✅，失败显示❌并保留进度。任务简报位于右下角。恢复任务沿用原参数，从剩余批次继续；新默认设置不改写已有任务。

采集篮、最多20个未完成任务、最近8次搜索、本地文件索引和最近5,000条下载历史保存在 `%LOCALAPPDATA%\MOKU\library\`。恢复的任务默认暂停；删除历史记录不删除下载文件。程序升级继续使用现有数据目录与 Windows 凭据命名空间。

## 请求模式与网络

在「我的账号 → 设置」选择：

| 模式 | 下载并发 | 特点 |
| --- | --- | --- |
| 安全（默认） | 单路 | 较宽松的请求间隔，优先前台操作 |
| 普通 | 最多两路 | 空闲时准备后续页面 |
| 激进 | 最多四路 | 更多预加载，提前准备动图帧包 |

搜索、预览和下载共用请求调度，遇到限频会等待冷却。普通读取期间可切换页面，旧读取结果不会覆盖新页面；下载时继续保护勾选与登录方式切换。

支持 Windows 本机 HTTP 代理或 TUN，不修改系统网络设置。通过 `HTTPS_PROXY` 指定代理时只接受本机代理地址。使用说明中的网络检测分别检查 Pixiv 主站和图片线路，使用匿名请求，不能代替账号授权。

动图预算可通过 `MOKU_UGOIRA_MAX_MIB`、`MOKU_UGOIRA_TEMP_MIB` 和 `MOKU_UGOIRA_TIMEOUT_SECONDS` 配置；可用范围分别为40–4096MiB、128–16384MiB、30–3600秒。MP4 默认CPU编码，`MOKU_UGOIRA_MP4_ENCODER=nvenc` 可选择相应 NVIDIA 编码器，失败时回到CPU路径。

## 从源码运行

准备 Python 3.12、WebView2 Runtime，在 PowerShell 中运行：

```powershell
git clone https://github.com/Xirti/Pixiv-Bulk-Image-Downloader.git
cd Pixiv-Bulk-Image-Downloader
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.lock
python moku_app.py
```

## 构建便携版

在上述虚拟环境中安装构建依赖，并准备 Node.js 以执行 JavaScript 语法检查：

```powershell
python -m pip install -r requirements-build.lock
powershell -ExecutionPolicy Bypass -File .\make-release.ps1
```

便携程序生成在 `dist\MOKU\`，发布压缩包、校验文件和更新说明生成在 `release\v版本号\`。
